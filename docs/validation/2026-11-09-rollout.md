# Aroki module rollout, 9–10 November 2026

## Compatibility and release state

The six updates below are published in the existing signed main collection and verified by read-back. They use capabilities already present in App Store Aroki **2.1.36**, and passed the same reader/store checks for the newer **2.1.37** candidate. No app-engine source, App Store binary, account, purchase, download or library data was changed in this task.

Production connector IDs and family IDs are unchanged: main-collection installs update in place rather than receiving duplicate sources. This does not silently migrate separately named Logo Test families. Modules requiring shipped typed-context/comment capabilities declare minimum 2.1.36; readers below that minimum retain installed older modules. The archived `legacy-before-2.1.36` branch is recovery history, not an automatic alternate update channel.

## What changed

- **AniKoto/Synthetiq Anime:** bounded unique identity selection instead of unsafe first-result mapping. AniKoto also repairs visible-title/year query context and normalises already-authorised absolute versus opaque media/caption values.
- **AniKage:** normalises already-absolute media/caption URLs without accidentally double-prefixing the CDN. No new host or provider.
- **Anime-Sama:** enables the shipped legacy-comment reader and repairs video catalogue discovery/filtering. Scan-only/webtoon-only entries are excluded, while video/mixed Anime+Scan/Film entries remain.
- **AniPM/Flux:** verify the requested audio is declared available and effective language matches it before creating a playback session. Zero additional requests, no JavaScript, no implicit Dub-to-Sub substitution, and unchanged caption/expiry routing. Naruto E1 Dub started natively on both; Dawang Raoming E1 Dub was rejected at the availability guard on both. Spoken language was not independently verified.

## Unchanged or held

- AnimeGG **1.1.1**: 37/50 released-title native starts (74%). No evidenced upstream repair required a no-op version bump.
- OnePace **2.2.1**: 50/50 sampled episodes from 491 returned episodes passed. This is one series, not 50 anime titles.
- AniWorld **0.3.2**: held, not represented as meeting the target. Released-title profile 26/50 starts, 21 unresolved matches and three failures. Search can return non-series pages; its fixed JSON route mapping wrongly treats those as series IDs. Other official hosters require unported dynamic handling. No speculative source/season mapping is released.
- ONE remains **retired**, not deleted or relisted.
- `update-flow-test` is a repository fixture, not a catalogue source or reliability result.

Black Clover on Anime-Sama, Case Closed E1 Dub/Saiki on AniKoto, and other provider-specific failures are explicitly retained in [known limitations](2026-11-09-known-limitations.md). In particular, source-root playback does not establish that Anime-Sama's exact sequel/season search coverage is fixed.

## Evidence and limits

The combined released-core regression suite passed **593 tests**, with **22 skipped**, zero failures. Actual ConnectorStore fixtures tested install, in-place upgrade, restart and fresh install at 2.1.36/2.1.37, preserving one installed family and rollback bytes; a below-minimum reader kept its older module. Publication workflows independently reran the pinned released validator's applicable tests, verified current/archived signatures, signed exact reviewed bytes and verified the complete repository after signing.

Native proof is macOS AVPlayer playhead advancement; some earlier profiles explicitly identify native-only fallback separately from bounded HTTP media validation. It is not physical iPhone/iPad acceptance, visible-frame/audible-language proof, ten-minute playback, full subtitle synchronisation, every episode/quality, or Wi-Fi/mobile testing. Later AniPM/Flux profiles each had HTTP-media-plus-native proof for every successful cell.
