# Synthetiq Flux 0.1.5 reviewed release

Compatible with released App Store Aroki 2.1.36 and the newer 2.1.37 reader. The app engine is unchanged. Connector ID/family remain `synthetiq-anime-direct`, preserving in-place module updates and saved-title identities. Readers below 2.1.36 retain installed older modules rather than accepting an unsupported update.

Exact artifact SHA-256: `2a3a8ab6dedb955e3b348c8c03558f00591c341d653305fff6b99865eb84800b`.

This adds the same two shipped declarative audio-contract guards as AniPM 0.1.3: the selected variant must be available and effective language must equal the requested Sub/Dub. The graph stops before session creation if either declaration is missing, malformed or conflicting. It adds no request/host and preserves canonical AniList identity routing, strict final-media allowlisting, episode/audio request parameters, supplied captions and expiry extraction. There is no JavaScript, new runtime, implicit cross-language fallback, or new app-engine requirement.

Live frozen released-title profile: **49/50 (98%)** passed both bounded HTTP media validation and macOS native-player advancement. One failure, 5 Centimeters per Second, returned HTTP 404. All 50 remain in the denominator. No access/rate-limit halt occurred. Corpus SHA-256: `27857cf9be9aed1df4add9425f38d350e4b225af006350bcfa34c77f00945314`. This is a fresh corpus, not a paired numeric comparison with the older 48/50 baseline.

Actual released-engine fixtures cover valid Sub/Dub, invalid/false/missing availability, opposite/unknown/missing effective language, 429 stopping the graph, rejection before session creation, candidate/baseline semantic equality and the six existing canonical-route/episode/audio/caption/expiry regressions. A conflicting Dub-to-Sub bootstrap now stops after two requests rather than relying on a later provider 424. The combined regression suite passed 593 tests with 22 skipped and zero failures; the final portable focused fixtures passed 14 tests. ConnectorStore install, update, restart and fresh install passed for both current/new app versions, retaining one installed family and rollback bytes.

Supplemental live Dub checks: Naruto episode 1 advanced natively with an explicit Dub request on both Flux and AniPM. Dawang Raoming's first-episode Dub request was rejected at `audioAvailable` on both, rather than playing an implicit Sub route. No 403/429 occurred. These four observed cases are recorded separately and are not added to the 50-title score.

Limits: macOS playhead advancement is not physical iPhone/iPad playback, proof of spoken language, ten-minute playback, complete subtitle synchronisation or every episode/quality. The module cannot supply a provider-missing title or add new error wording/greyed-out audio controls to the existing app.
