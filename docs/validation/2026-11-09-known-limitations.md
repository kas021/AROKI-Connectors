# Remaining limitations after the reviewed module rollout

All proposed improvements must run on released Aroki 2.1.36 as well as the newer reader. No unshipped parser capability or JavaScript runtime is a dependency of a published module.

- **AniKoto:** 42/50 released-title profile successes do not establish a fix for every named report. Keroro first Sub and Komi middle Sub passed exact regressions; Case Closed first Dub and Saiki middle Sub ended in unresolved chains. Yamada OVA was not probed because its cross-catalogue identity was not corroborated. No wrong-title fallback was used to turn those into passes.
- **Anime-Sama:** 39/50 video catalogue roots passed; Black Clover remains unresolved in a separate source-bound chain. Video-root playback coverage must not be confused with exact sequel/season search coverage.
- **AniPM:** the new released-title sample produced eight HTTP-404 title chains and four unresolved strict matches. Static routing matches official Player; no invented ID conversion is justified. The module guard prevents conflicting audio from reaching session creation but cannot add a source video, fix its catalogue, or change the released app's error wording.
- **AniWorld:** the released-title profile was 26/50 native successes, 21 unresolved title matches and three failures. The 21 are not confirmed absent. Blue Exorcist and Tokyo Ghoul returned no native-playable candidate. MHA S4's exact search returns a same-origin non-series page, which Aroki wrongly turns into a series slug; official Player rejects non-`/anime/stream/` links. Its returned JSON has only title/description/link, with no type declaration. A generic prefix filter/first-series-component guard cannot be expressed with the released reader's fixed JSON equality filters and transforms; no arbitrary regex or season remapping is added. The actual result page had no episode links or episode-like JSON-LD. Existing Vidmoly mirrors match the official language keys; the other official hosters require provider-specific dynamic handling that has not been safely translated. No speculative host/season remapping or no-op version bump is released.
- **ONE:** remains retired by owner instruction. It is not deleted or relisted as an installable source.

Native results in these reports mean bounded HTTP media checks and/or explicitly identified macOS native playhead advancement. They are not physical iPhone/iPad acceptance, spoken-language verification, complete caption synchronisation, all quality options, every episode, ten-minute playback, or Wi-Fi/mobile-data coverage. Each underlying report preserves failed/unresolved/blocked cells in its denominator.
