App compatibility: existing App Store Aroki 2.1.36 and private 2.1.37 reader; no engine changes. Same connector ID and family, with an in-place version upgrade. Apps below 2.1.36 retain installed older modules rather than accepting unsupported features. Original signed repository is archived on `legacy-before-2.1.36`; this is not an automatic dual-track feed.

Mixed Anime + Scan cards remain eligible. No JavaScript execution, extra media hosts, or audio-group changes.
